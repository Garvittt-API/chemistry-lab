# Responsive Layouts

The Phase 02 web foundation uses deliberate layout changes rather than simply shrinking desktop
content:

- **Wide screens:** full navigation, two-column hero/detail layouts, sticky filters and detail index,
  dense subject grid.
- **Tablet:** navigation collapses, content remains within a readable container, filter controls form
  a compact row, and detail metadata becomes a secondary grid.
- **Mobile:** a button-controlled navigation menu, one-column reading flow, horizontally scrollable
  detail index, one-column filters, stacked cards and reachable touch targets.

Long tables and equation blocks scroll horizontally rather than clipping content. Text remains the
primary source of meaning, and future apparatus views must preserve a readable alternative outside the
visualization area.
