# Visual Assets

Phase 02 uses the `lucide-react` icon library for interface icons. Icons are decorative when adjacent
to visible labels and use `aria-hidden="true"`; icon-only controls have accessible names and titles.

No stock photography, third-party educational diagrams, laboratory renders or unlicensed chemistry
assets were added. The visual identity is carried by typography, semantic color, layout rules and
original CSS composition. Future assets require provenance, license, alternative text and an entry in
`THIRD_PARTY_NOTICES.md`.
