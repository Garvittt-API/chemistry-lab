# ADR-003: Web-First and Selective 3D

- Status: Implemented in Phase 01 direction; project-owner review pending
- Date: 2026-11-03

## Context
The project has a broad long-term scope and limited initial development capacity. Full 3D for every experiment would increase performance, accessibility and maintenance costs.

## Decision
Build the first complete learning experiences on web with 2D interaction. Add 3D only when it materially improves spatial or molecular understanding. Scaffold mobile early enough to validate shared contracts, but do not require full feature parity in the first MVP.

## Consequences
- Earlier delivery of useful learning experiences.
- More time for scientific model validation.
- Some 3D concepts may arrive later.
- Mobile release follows a separate device and UX acceptance gate.
