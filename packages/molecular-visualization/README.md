# Molecular visualization contracts

Framework-independent molecular structures, validated catalog data, geometry helpers, accessible descriptions and visualization state. This package does not calculate chemistry beyond coordinate measurements and delegates molar mass to `simulation-core`.

Coordinates are in ångström. Every record declares whether it is experimental reference geometry or an idealized educational construction. All records remain `pending_scientific_review`; schema validation is not scientific validation.

See `../../docs/science/molecular-geometry.md` and `../../docs/architecture/3d-visualization.md` for contracts, references and limitations.
